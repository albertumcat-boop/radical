Configuración

⚙️ Cómo configurar el acceso de administrador
1. Ve a Firebase Console → tu proyecto → Firestore Database
2. Crea la colección admins
3. Añade un documento con tu Firebase UID como ID del documento
4. Contenido: {"email": "tu@email.com"}
5. Recarga esta página y serás reconocido como admin

🖼️ Imágenes — Opciones de almacenamiento
Opción 1 (más fácil): Pega cualquier URL de imagen (Imgur, Cloudinary, Google Drive, etc.)
Opción 2 (upload directo): Sube directamente a Firebase Storage
→ Firebase Console → Storage → Reglas → permite escritura para admin
Opción 3: Usa Cloudinary (plan gratuito, 25GB)
🎬 Videos — Opciones de hosting
Preview público (trailer): YouTube o Vimeo — pega el link embed
Video de pago (el curso): Vimeo Pro → URL privada, o Firebase Storage
→ El comprador accede al video URL desde su perfil tras la compra
